# Nexora — Windows Customization Hub

Центр кастомизации Windows 10/11: панель задач, оформление, расширения, профили. Приложение само проверяет обновления здесь: страница **Releases**.

Установка: скачайте `WindowsCustomizationHub-Setup-*.exe` из последнего релиза и запустите. Дальше обновления ставятся кнопкой «Обновить сейчас» в Настройках.

Исходники приложения открыты; готовые установщики лежат в Releases.

## Для разработчика
Релиз создаётся автоматически: после изменения `version` в `package.json` и пуша в `main` GitHub Actions собирает установщик, создаёт `update.json` и публикует релиз. Подписанные пакеты расширений лежат в `repository/` (ключ подписи хранится отдельно и в репозиторий не попадает).
