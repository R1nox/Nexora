# Nexora — Windows Customization Hub

Центр кастомизации Windows 10/11: панель задач, оформление, расширения, профили. Приложение само проверяет обновления здесь: страница **Releases**.

Установка: скачайте `WindowsCustomizationHub-Setup-*.exe` из последнего релиза и запустите. Дальше обновления ставятся кнопкой «Обновить сейчас» в Настройках.

В репозитории хранятся только готовые установщики и `update.json`.
